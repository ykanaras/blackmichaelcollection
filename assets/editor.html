Owner workspace · Local file helper

Keep the collection current.

Edit your content below, validate it, and download the updated JSON file. Replace the matching file in your GitHub repository’s content/ folder. Your hosting build must then run python3 scripts/build.py.

This page does not save to GitHub or publish changes. It has no login and is not a private dashboard. Never enter passwords, customer information or payment secrets here. Keep a downloaded copy before switching files.

Quick editing guide

Products: add a unique slug, category (minerals, gemstones or jewelry), original image path, details, a numeric price, status (preview, available or sold), and an optional HTTPS checkoutUrl. Keep unknown details out of live listings.

Events: include start and end with timezone offsets, timezoneLabel, venue, address, city, booth, admission and organizer URL. The site automatically separates past events when rebuilt.

Journal: add a slug, title, description, category, date, and sections containing heading and text. Sources are optional links. Content is plain text and safely escaped.

Site settings: keep preview true until the catalog, domain and business policies are confirmed. Set siteUrl to the public HTTPS domain without a trailing slash. Email is optional; without it the inquiry tool composes a message to copy into Instagram.
